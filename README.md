# STARTUP SCRIPT
Custom Scripts used for quickly configurating a testing enviroment for testing ros2 networks and docker.


# HOW TO SET UP ROVER
## STARTUP VARIABLES

|VARIABLE NAME|DEFAULT VALUE|WHAT THIS VARIABLE DOES|
|---|---|---|
|PACKAGE|NONE|THE PACKAGE THAT DOCKER USES|
|SUBNET|1|THE SUBNET THAT THE CONTAINER WILL BE CONNECTED TO (0-255)|
|ENV_VAR_NAMES|('ROS_AUTOMATIC_DISCOVERY_RANGE')|THE ARRAY OF ENVIROMENT VARIABLES THAT ARE USED WITHIN THE CONTAINER|
|ENV_VAR_EXP_VALUES|('SUBNET')|THE ARRAY OF EXPECTED VALUES MATCHING TO THE ENVIROMENT VARIABLE LIST|
|IP_ADDR_FINAL_DIGIT|10|THE FINAL DIGIT(S) OF THE IP ADDRESS (0-255)|
|IP_ADDR_CLASS|'192.168'| THE FIRST TWO SEGMENT OF THE IP ADDRESS (0-255).(0-255)|


## STARTUP STEPS
1) Open `STARTUP-ROVER.BASH` in a text editor
2) Add package by replacing value of `PACKAGE` variable
3) Adjust any of the all of the other global varable to meet your needs (see the list above for a description of what they do)
